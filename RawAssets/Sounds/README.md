# 전투 효과음 (절차적 생성)

`generate_sfx.py`로 생성한 44.1kHz / 16bit / 모노 WAV 17종입니다. 외부 라이선스가 없는
자체 생성물이라 그대로 상용/제출용으로 써도 됩니다.

## 파일 목록

### 플레이어 (검)

중세 롱소드 기준, 4타 콤보용으로 단계마다 성격을 다르게 잡았습니다.
250Hz 이하 저역이 전부 0.5% 미만이라 바람소리처럼 웅웅대지 않고, 밝기(스펙트럼 중심)는
3.7~4.5kHz로 날이 서 있습니다.

| 파일 | 길이 | 용도 |
| --- | --- | --- |
| `SFX_Player_SwordSwing_01` | 0.37s | 콤보 1타 — 빠른 가로베기 |
| `SFX_Player_SwordSwing_02` | 0.31s | 콤보 2타 — 되받아치는 역베기 (가장 짧고 높다) |
| `SFX_Player_SwordSwing_03` | 0.48s | 콤보 3타 — 큰 호를 그리는 베기 |
| `SFX_Player_SwordSwing_04` | 0.84s | 콤보 4타 — 회전 후 마무리 내려베기 (준비 바람 + 긴 강철 여운) |
| `SFX_Player_SwordHit_Flesh` | 0.34s | 몬스터에 적중 (베어 들어가는 느낌) |
| `SFX_Player_SwordHit_Hard` | 0.85s | 방패·바위·골렘 등에 튕김 (금속 링) |

> **4타는 앞에 0.10초 준비 바람이 붙어 있습니다.** 노티파이를 칼이 움직이기 직전에 걸어야
> 준비 바람과 실제 스윙이 맞물립니다. 1~3타는 선행 구간이 없으니 스윙 시작 프레임에 그대로 두면 됩니다.
> 각 파일의 뒷부분은 대부분 강철 여운이라, 다음 타가 겹쳐 들어와도 서로 방해하지 않습니다.

### 몬스터 공격

| 파일 | 길이 | 용도 |
| --- | --- | --- |
| `SFX_Mon_Goblin_Attack` | 0.52s | 고블린 — 째지는 기합 + 가벼운 무기 휘두르기 |
| `SFX_Mon_Larvae_Attack` | 0.55s | 라바 — 낮은 그르렁 + 젖은 스퀄치 + 물기 |
| `SFX_Mon_Narbash_Attack` | 0.85s | 나르바쉬 — 둔기 스윙 + 북 같은 저역 타격 |
| `SFX_Mon_Bird_Attack` | 0.75s | 버드 — 날갯짓 2회 + 울음 + 쪼기 |
| `SFX_Mon_Bug_Attack` | 0.60s | 버그 — 턱 딱딱거림 + 껍질 마찰 + 찌르기 |
| `SFX_Mon_Golem_Attack` | 1.58s | 골렘 — 돌 갈리는 준비동작 + 내려찍기 (선딜 약 0.48s) |

> `SFX_Mon_Golem_Attack`은 준비동작이 앞에 0.48초 붙어 있습니다. 몽타주에서
> **내려찍는 순간이 아니라 팔을 들어올리기 시작할 때** 노티파이를 걸어야 타이밍이 맞습니다.

### 몬스터 피격 (Hit 모션용)

`UMonsterAnim::Hit()`이 재생하는 피격 리액션 몽타주(`m_pMTGHit`)에 붙이는 소리입니다.
검이 파고드는 순간을 몬스터마다 **다른 재료**로 만들었습니다.

| 파일 | 길이 | 재료 |
| --- | --- | --- |
| `SFX_Mon_Goblin_Hit` | 0.34s | 마른 몸 — 얕은 뼈에 날이 걸리는 딱 + 캑 하고 끊기는 단발 비명. 가장 짧고 높다 |
| `SFX_Mon_Larvae_Hit` | 0.46s | 물주머니 파열 — 단단한 것이 하나도 없다. 대역이 아래로 훅 꺼지고 체액 16방울 |
| `SFX_Mon_Narbash_Hit` | 0.50s | 두꺼운 살 + 가죽 — 묵직한 중저역, 배에서 밀려 나오는 낮은 신음 |
| `SFX_Mon_Bird_Hit` | 0.42s | 깃털 터짐 + 속 빈 가는 뼈 두 대 + 째지는 울음. 가장 밝다 |
| `SFX_Mon_Golem_Hit` | 0.80s | 돌 — 살점 요소 없음. 튕긴 검날의 강철 울음 + 표면 균열 + 파편 20개 |

> **북소리처럼 들리던 원인은 음정이 있는 저역 사인(`thump`)을 몸통으로 쓴 것이었습니다.**
> 지금은 전부 노이즈 기반 임팩트라 기본 주파수가 생기지 않습니다. 50~500Hz를 좁은
> 밴드패스로 훑어 잰 드럼 점수가 실제 북(`Narbash_Attack`) 1.74 대비
> 고블린 0.09 / 라바 0.13 / 버드 0.02 / 골렘 0.06입니다.
> 나르바쉬만 1.63으로 높게 나오는데, 이는 타격이 아니라 **신음 목소리의 378Hz 포먼트** 때문입니다
> (타격 몸통만 떼어 재면 0.08). 목소리가 음정을 갖는 건 정상이고, 실제 북은 89Hz에서 울려 성격이 다릅니다.
> 신음이 거슬리면 `narbash_hit()`의 `grunt` 게인 `0.65`를 낮추세요.

> 다섯 개 모두 **같은 검**에 맞는 소리라 앞머리에 아주 옅은 강철 링이 공통으로 깔려 있고,
> 대신 기준 주파수를 대상에 따라 다르게(고블린 2.9k / 라바 2.4k / 나르바쉬 2.05k /
> 버드 3.2k / 골렘 2.15k + 긴 여운) 잡았습니다. 같은 무기인데 맞는 대상이 다르다는 느낌이 납니다.
> 버그(Bug)는 아직 피격음이 없습니다.

## 에디터 작업 (사용자가 직접)

1. **임포트** — 콘텐츠 브라우저에서 `Content/UE_Asset/Sounds/` 로 이동 후 위 WAV들을 드래그.
   - 임포트된 `USoundWave`의 **Compression Quality**는 40~60이면 충분합니다.
   - **Sound Class**는 `SFX` 계열이 있으면 지정, 없으면 그대로 둬도 됩니다.
   - 모노라서 3D 감쇠(Attenuation)가 정상 동작합니다. 몬스터 소리에는
     `Attenuation Settings`를 꼭 지정하세요 (없으면 맵 전역에서 같은 크기로 들립니다).

2. **콤보 연결** — 스윙 4종은 콤보 1/2/3/4타에 **하나씩 고정으로** 배치하세요.
   랜덤으로 섞으면 단계별 성격 차이가 사라집니다. 반복이 지겨우면 각 Sound Cue에
   `Pitch Shift`를 ±0.05 정도만 걸어 미세하게 흔들면 충분합니다.

3. **몽타주에 연결** — 각 공격 애님 몽타주 타임라인에서 우클릭 →
   *Add Notify > Play Sound* → 위 사운드 지정.
   - 공격 스윙: 무기가 움직이기 시작하는 프레임.
   - 몬스터 피격(`_Hit`): 피격 리액션 몽타주 시작에서 1~2프레임 뒤.
   - 코드 수정은 필요 없습니다 — 기존 애님 노티파이 방식 그대로 붙습니다.

4. **스킬 이펙트에 붙이는 경우** — `AEffectDestroy` 계열 블루프린트의
   `SoundTemplate` 프로퍼티에 지정하면 `SpawnVFX`가 나이아가라와 함께 재생합니다
   (`Source/Capstone/EffectDestroy.cpp:62`의 `PlaySoundAtLocation`).

## 볼륨 기준

전부 피크 정규화(−1dBFS) + RMS 상한 −14dB로 맞춰져 있어 서로 비슷한 크기로 들립니다.
그래도 믹스에서 조정이 필요하면 대략 이 정도가 무난합니다.

- 플레이어 스윙: Volume Multiplier `0.7` (4타만 `0.85`로 조금 더 크게)
- 적중음: `1.0`
- 몬스터 공격: `0.8` (골렘/나르바쉬는 `1.0`)
- 몬스터 피격: `0.9` (골렘만 `1.0`)

## 다시 만들기 / 튜닝

```bash
"C:/Epic_Game/UE_5.7/Engine/Binaries/ThirdParty/Python3/Win64/python.exe" RawAssets/Sounds/generate_sfx.py
```

표준 라이브러리만 쓰므로 별도 설치가 필요 없습니다. 스크립트 아래쪽의 사운드별 함수에서
길이·주파수·게인 숫자를 바꾸고 다시 실행하면 그대로 재생성됩니다. 주요 파라미터는 다음과 같습니다.

- `whoosh(dur, f_lo, f_hi, peak, q, air)` — `f_hi`를 올리면 더 날카롭고, `dur`을 늘리면 더 묵직합니다.
- `growl(dur, f0_a, f0_b, formants, rough, vib_rate)` — `f0`를 낮추면 큰 몬스터, `rough`를 올리면 더 거칠어집니다.
- `thump(dur, f0, f1)` — 타격의 저역 무게. `f0`를 올리면 가벼워집니다.

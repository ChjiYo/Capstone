# 10단계: 대본 (전체 대사 · 데이터 입력용)

## 목표

9단계에서 정한 챕터 구성에 들어갈 **모든 대사를 확정**하고, 그대로 `DT_Dialogue` DataTable에 넣을 수 있는 형태로 정리한다. 11단계 코드와 12단계 위젯은 여기서 정한 **대사 ID**를 그대로 참조한다.

## 선행 단계

9단계(스토리 설계).

## 읽어야 할 파일

`Docs/09_story_design.md`(인물/챕터 구성)만 읽으면 된다. 코드 불필요.

## 설계

### 1. 대사 ID 명명 규칙

```
DL_<챕터>_<장면>_<번호 2자리>
```

| 구성 | 값 |
|---|---|
| 챕터 | `P`(프롤로그) / `C1`~`C4`(1~4장) / `BOSS` / `EPI` |
| 장면 | `INTRO`(퀘스트 제안 전) / `PROG`(진행 중 재대화) / `DONE`(완료 후 재대화) / `MEET`(조우) / `P2`(페이즈2) / `DEAD`(사망) / 없음 |
| 번호 | `01`부터. **재생 순서 = 번호 순서** |

예: `DL_C2_INTRO_03` = 2장 퀘스트 제안 대사 3번째 줄.

### 2. DataTable 행 필드 (11단계 `FDialogueLine`과 1:1)

| 필드 | 타입 | 설명 |
|---|---|---|
| `Row Name` | FName | 위 규칙의 대사 ID |
| `SpeakerName` | FText | 화자 이름. **나레이션은 비워둔다** |
| `LineText` | FText | 대사 본문 |
| `bIsNarration` | bool | true면 초상화/이름표를 숨기고 화면 전체를 어둡게 깐다 |
| `AutoAdvanceTime` | float | 0이면 입력을 기다린다. 0보다 크면 그 초 후 자동으로 다음 줄 (전투 중 짧은 대사용) |
| `PortraitIcon` | TSoftObjectPtr\<UTexture2D\> | 없으면 비워둠 (자동 숨김) |

### 3. 표기 규칙

- **말줄임표는 `…`(U+2026) 한 글자**로 통일한다 (`...` 금지 — 폭이 들쭉날쭉해진다).
- 한 줄은 **공백 포함 45자 이내**. 대사창은 2줄까지만 예쁘게 나온다 (12단계 명세 기준).
- 대사 안에 쉼표가 있으면 CSV로 넣을 때 반드시 `"`로 감싼다.

## 퀘스트 텍스트 교체분

기존 `QuestChain` 4항목의 제목·설명을 스토리 톤으로 바꾼다. 챕터 라벨/제목은 11단계에서 `FQuestData`에 추가되는 필드다.

| # | QuestID | 챕터 라벨 | QuestTitle | QuestDescription |
|---|---|---|---|---|
| 0 | `Q_Herb` | 제 1장 | 살아남은 사람들 | 무너진 밭에서 약초 5뿌리를 모아 하란에게 전한다. |
| 1 | `Q_Goblin` | 제 2장 | 놈들의 앞잡이 | 마을 어귀를 맴도는 고블린 5마리를 정리한다. |
| 2 | `Q_Enhance` | 제 3장 | 부러진 검 | 고든에게 스승의 검을 맡겨 다시 벼린다. |
| 3 | `Q_Narbash` | 제 4장 | 잿불의 성문 | 북쪽 성문 너머로 들어가 나바쉬를 벤다. |

> `QuestID`는 기존에 쓰던 값이 있으면 **그 값을 유지**한다 (포탈의 `RequiredQuestID`, 트래커 등이 참조 중). 위 표의 ID는 아직 정해두지 않았을 때의 권장값이다.

## 에디터 작업 (사용자)

1. 위 CSV를 `RawAssets/DT_Dialogue.csv`로 저장 (UTF-8).
2. **11단계 코드가 빌드된 뒤에** 콘텐츠 브라우저 → 임포트 → 행 구조체 `FDialogueLine` 선택 → `Content/UE_Asset/Data/DT_Dialogue` 로 생성. (`Data` 폴더가 없으면 만든다. 1단계의 `DT_Item`이 있다면 같은 폴더에 둘 것.)
3. 하란 NPC의 `QuestChain` 4항목에 위 "퀘스트 텍스트 교체분" 표대로 제목/설명을 갱신한다 (대사 ID 연결은 11단계 문서 참조).

## 완료 기준

- [ ] 대사 ID 명명 규칙을 어기는 행이 없다 (11단계 코드가 ID로만 대사를 찾는다).
- [ ] CSV 임포트 후 `DT_Dialogue` 행 수가 **41개**이고, 한글이 깨지지 않는다.
- [ ] 대사 한 줄이 45자를 넘지 않는다 (넘으면 대사창에서 3줄로 흘러 잘린다).

# 20. 미니맵 간략 지도 (확대 + 모든 레벨 표시)

미니맵 배경을 위성 사진처럼 찍던 방식에서, **걸을 수 있는 곳/막힌 곳을 단순한 색 면으로 그린 간략 지도**로 바꿨습니다.
조명과 무관하게 그리므로 들판(밤)·동굴처럼 어두운 레벨에서도 지도가 보입니다.

## 1. 바뀐 점

| 항목 | 이전 | 지금 |
|---|---|---|
| 확대 | 반경 40m (`MinimapWorldRadius` 4000) | 반경 20m (2000). 2배 확대 |
| 배경 | 0.2초마다 위에서 찍은 실제 화면 | 레벨 시작 시 한 번 구운 간략 지도 (멀리 가면 다시 구움) |
| 들판/동굴 | 조명이 어두워 검게 보여서 미니맵이 없는 것처럼 보였음 | 조명 없이 찍으므로 항상 보임. 동굴은 천장을 잘라 바닥 모양을 그림 |
| 원형 테두리 | 마스크가 256px로 그려져 틀(200px) 밖으로 삐져나옴 | 지도 크기(180px)에 맞춤 |

지도 색:

- 걸을 수 있는 곳: 풀밭(연두) / 흙(베이지) / 포장길·돌바닥(밝은 베이지)
- 막힌 곳: 바위·건물(회색), 붉은 지붕(빨강), 나무(진초록), 동굴 벽(짙은 회갈색)
- 갈 수 없지만 자연 지형인 곳(마을 바위 울타리 밖 등): 어두운 풀/흙색
- 걸을 수 있는 곳과 막힌 곳의 경계에 진한 외곽선, 막힌 곳 오른쪽 아래에 그림자

## 2. 구조

- `MinimapBaker.h/.cpp` (신규) `UMinimapBaker`: `UUI_Minimap`이 `InitMinimap`에서 만들고 `NativeTick`마다 `Tick`을 부릅니다.
  1. `APy_Grey::MinimapCaptureComponent`로 플레이어 주변 160m를 위에서 정사영으로 **한 번** 찍습니다
     (`SCS_SceneColorSceneDepth`, 조명/안개/캐릭터/파티클/풀 끔 → RGB = 재질 원래 색, A = 깊이).
     엔진 기본 정사영 원평면은 사실상 무한대라 깊이가 뭉개지므로 투영 행렬을 직접 넣습니다.
  2. GPU → CPU 복사는 `FRHIGPUTextureReadback`으로 비동기(게임 스레드 멈춤 없음).
  3. 찍힌 높이로 플레이어 머리 위가 막혀 있으면(동굴) 플레이어 4.5m 위에서 잘라 다시 찍습니다 (실내 모드).
  4. 백그라운드 스레드에서 지도로 변환(약 0.8~1.6초):
     - 걸을 수 있는 바닥 = **내비메시 다각형**(들판/동굴). 내비메시가 없는 레벨(마을)은 높이의 경사/턱으로 추정하고,
       플레이어와 이어진 덩어리만 남깁니다 (바위 속 섬 제거).
     - 재질 색의 색상/채도/명도로 풀/흙/길/지붕/나무/바위를 나누고 다수결 필터로 얼룩을 지운 뒤 외곽선/그림자를 칠합니다.
  5. 결과를 밉맵 포함 `UTexture2D`로 만들어 교체합니다.
- `UUI_Minimap::UpdateMapBackground`: 구운 지도에서 플레이어 주변만 UV 영역으로 잘라 보여주고, 플레이어 방향에 맞춰 회전합니다.
  회전한 사각형 모서리가 틀 밖으로 나가지 않도록 `NativeMapClip`(SizeBox, ClipToBounds)에 넣었습니다.
- 플레이어가 구운 영역 중심에서 `MapBakeWorldSize/2 - MinimapWorldRadius - 25m`(지금 35m) 넘게 벗어나거나,
  실내에서 3.5m 넘게 오르내리면 다시 굽습니다. 다 구워질 때까지는 이전 지도가 그대로 보입니다.
- `APy_Grey`의 예전 주기 캡처(`SetupMinimapCapture`/`UpdateMinimapCapture`, `MinimapCaptureHeight` 등)는 삭제했습니다.
- `Capstone.Build.cs`에 `RenderCore`, `RHI`, `NavigationSystem` 추가.

## 3. 조정하는 법 (`WBP_Minimap` Class Defaults 또는 `UI_Minimap.h` 기본값)

- `Minimap World Radius`: 확대 정도. 작을수록 크게 보입니다 (기본 2000 = 반경 20m).
- `Map Bake Resolution` / `Map Bake World Size`: 지도 해상도(2048)와 한 번 굽는 영역(160m). 해상도를 낮추면 굽기가 빨라집니다.
- 색/분류 기준은 `MinimapBaker.cpp`의 `MinimapStylize` (`Palette`, `IsGreen`, `IsRoof` 등).

## 4. 에디터 작업 (사용자)

## 5. 검증한 내용

에디터를 닫은 상태에서 게임을 직접 실행해 임시 테스트 코드로 확인했습니다 (테스트 코드는 삭제함).

- `Lv_Village`, `Lv_OpenField`, `LV_Cave` 세 레벨 모두 미니맵 지도가 보임 (스크린샷).
- 플레이어를 90도 돌리면 지도와 포탈 마커가 함께 회전, 55m 순간이동 시 새 위치로 다시 구워짐.
- 동굴은 야외로 한 번 찍은 뒤 실내로 판정되어 천장을 잘라 다시 찍음.
- **확인하지 못한 것**: `Lv_Boss`/`Lv_DefaultField`의 화면, 아주 빠르게 이동할 때 다시 굽는 동안의 모습(로직상 25m 여유).

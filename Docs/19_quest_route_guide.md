# 19. 퀘스트 길 안내 (다른 레벨의 목표 → 포탈 마커)

퀘스트를 받았는데 목표(몬스터/약초/NPC)가 **다른 레벨**에 있으면, 미니맵 퀘스트 마커와 월드 웨이포인트가
목표 대신 **그 레벨로 가는 포탈**을 가리킵니다. 목표가 있는 레벨에 도착하면 원래대로 목표물 위에만 마커가 뜹니다.

## 1. 동작

| 상황 | 미니맵 퀘스트 마커 / 월드 웨이포인트 |
|---|---|
| 마을에서 고블린 토벌·약초·나바쉬 퀘스트 | 마을의 포탈(→ Lv_OpenField). 웨이포인트에는 `포탈 57m` |
| 들판에서 강화 퀘스트 | 들판의 마을 복귀 포탈(→ Lv_Village) |
| 들판에서 나바쉬 퀘스트 (`Narbash_Kill` 진행 중) | 동굴 포탈(→ LV_Cave) |
| 목표가 있는 레벨에 도착 | 가장 가까운 목표 몬스터/약초/NPC 위에만 마커 |
| 퀘스트 없음/완료 | 마커 없음. 미니맵의 "돌아가는 길" 포탈 마커(`bShowOnMinimap`)가 다시 보임 |

- 퀘스트 마커(목표든 포탈이든)가 떠 있는 동안에는 미니맵의 **돌아가는 길 포탈 마커를 숨깁니다** (퀘스트 위치에만 표시).
- 게이트 포탈(`RequiredQuestID`)은 그 퀘스트를 진행 중일 때만 길로 인정합니다.

## 2. 구조

- `QuestRoute.h/.cpp` (신규): `GetQuestLevels`(목표가 있는 레벨 후보)와 `FindRoutePortal`(지금 레벨에서 밟을 포탈).
  첫 걸음은 지금 레벨의 실제 `APortalPoint`(`GetTargetLevelName`/`GetRequiredQuestID`)로 판단하고,
  두 레벨 이상 건너야 하면 코드의 레벨 연결표(`StaticLevelLinks`)로 너비 우선 탐색합니다.
- `UQuestComponent::FindQuestTargetOrRoute`: 현재 레벨에서 목표를 못 찾을 때만 위 함수를 부릅니다.
  `GetQuestTargetActor`(미니맵과 웨이포인트 공용)가 이것을 쓰므로 두 마커가 함께 바뀝니다.
  목표를 계속 못 찾는 중에는 `TargetRefreshInterval`(0.3초)마다만 다시 탐색합니다.
- `UUI_QuestWaypoint::SetPortalGuide`: 포탈을 가리키는 중이면 거리 앞에 `포탈 `을 붙입니다.
- `FQuestData::TargetLevelName`(신규, 선택): 퀘스트 데이터에서 목표 레벨을 직접 지정합니다. 비우면 코드 표를 씁니다.

## 3. 조정하는 법

- 새 퀘스트 목표가 생기면 `QuestRoute.cpp`의 `QuestLevelTable()`에 한 줄 추가하거나, 퀘스트 데이터의 `Target Level Name`을 채웁니다.
- 새 레벨/포탈이 생기면 `StaticLevelLinks()`에 연결을 추가합니다 (지금 레벨의 포탈은 실제 배치를 읽으므로 두 번째 걸음부터만 필요).
- 현재 표 (레벨에 배치된 액터를 실제로 덤프해서 만듦):
  - `Lv_Village`: 강화 NPC, 포탈 → Lv_OpenField
  - `Lv_OpenField`: 고블린 6, 약초 5, 포탈 → Lv_Village / LV_Cave(`Narbash_Kill` 게이트)
  - `LV_Cave`: 나바쉬, 고블린 1 (포탈 없음)
  - `Lv_DefaultField`: 고블린 3, 포탈 → Lv_Boss (게임 흐름과 연결돼 있지 않은 테스트 레벨)

## 4. 에디터 작업 (사용자)

없음. (원하면 퀘스트 데이터의 `Target Level Name`만 채우면 됨)

## 5. 검증한 내용

에디터를 닫은 상태에서 게임을 직접 실행해 임시 테스트 코드로 확인했다 (테스트 코드는 삭제함).

- 마을: 고블린/약초/나바쉬 → 마을 포탈, 강화 → 강화 NPC.
- 들판(직접 실행): 강화 → 복귀 포탈(마을), 나바쉬 → 동굴 포탈(`Narbash_Kill`), 고블린/약초 → 실제 개체.
- 마을에서 고블린 퀘스트를 받고 포탈로 이동 → 들판에서 퀘스트가 복원되고 마커가 고블린으로 바뀜.
- 스크린샷: 마을에서 포탈 위 `포탈 57m` 웨이포인트 + 미니맵 마커, 들판 도착 후 고블린 `138m`만 표시되고 복귀 포탈 마커는 숨겨짐.
- **확인하지 못한 것**: 실제 `BP_Hans`를 통한 퀘스트 수락 흐름, 동굴 포탈 위 월드 라벨의 화면(로직은 같음), 소리.
